# Laboratorio de SIG y Percepción Remota · CICY

## Subir y publicar en GitHub Pages

1. Descomprime este ZIP.
2. Crea un repositorio en GitHub y sube el contenido descomprimido a su raíz. El archivo index.html debe quedar en la raíz del repositorio.
3. En Settings > Pages, selecciona Deploy from a branch.
4. Selecciona la rama main y la carpeta / (root), y guarda.
5. Espera a que GitHub muestre la dirección de tu sitio.

Incluye siete páginas, estilos, JavaScript y 37 imágenes. No requiere compilación. Conserva las carpetas y los nombres de archivo.

Para modificar el sitio, puedes editar los HTML, theme.css y site.js. El ZIP de código completo incluye también el contenido fuente y el generador Python.

Los PDF de las tesis continúan alojados en WordPress y los libros están enlazados a ResearchGate.
